欢迎来到 Morethan Log - 一个使用 Astro 构建的现代静态博客模板。

此模板的灵感来自流行的 [morethan-log](https://github.com/morethanmin/morethan-log) Next.js 模板，但为 Astro 从头重建。

## 功能特点

- 🚀 基于 Astro 构建，性能极致
- 🌐 完整的多语言支持（默认支持中文、英语和俄语）
- 📱 响应式设计，适配所有设备
- 🎨 简洁现代的界面
- 📝 支持 Markdown，轻松创作内容
- 🔍 内置搜索功能
- 📊 SEO 优化
- 🌙 支持深色模式

## 快速开始

1. Fork 这个仓库
2. 更新 `src/config/site.ts` 中的个人信息
3. 用你自己的内容替换示例内容
4. 部署到你喜欢的托管平台

## 技术栈

- **框架**: Astro
- **语言**: TypeScript/JavaScript
- **样式**: CSS
- **版本控制**: Git
- **部署**: Netlify/Vercel

欢迎根据你的需求自定义此模板！
